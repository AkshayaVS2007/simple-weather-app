🌦️ About Simple Weather App

About the Project

Simple Weather App is a web application that provides weather information for different cities in Kerala.

Features

• Current weather information

• Weather forecast

• Multiple Kerala cities

• Simple and user-friendly interface

Technologies Used

HTML – Structure of the web pages

CSS – Design and styling

JavaScript – Functionality

Open-Meteo API – Weather data

Git & GitHub – Version control and project hosting

Purpose

The purpose of this project is to create a simple web application that helps users check weather information easily.
